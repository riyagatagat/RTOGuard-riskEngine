METHOD
  risk_score = round(raw_probability * 100)   (e.g. 0.73 -> 73). No Low/Medium/High bands are defined here.
  Break-even logic: intervene on an order when  eff * p * RTO_cost > intervention_cost,
  i.e. p > intervention_cost / (eff * RTO_cost). Example: intervention = 25% of RTO cost, eff = 1 -> p > 0.25.
  This simple rule is NOT used alone: review capacity, false positives and grid results are also shown.
  Realised cost uses actual test outcomes; model-expected cost uses predicted probabilities only.
